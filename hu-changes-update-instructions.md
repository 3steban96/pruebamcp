# HU Changelog Auto-Update Instructions

> Instrucciones para agentes: Cómo actualizar el registro de cambios de una HU automáticamente.

## 🎯 Propósito

Mantener un registro único, rápido y consultable de todos los cambios realizados en cada Historia de Usuario (HU) sin esfuerzo manual.

---

## 📋 Cuándo Ejecutar

**El agente debe actualizar el HU changelog al finalizar CADA ITERACIÓN**:

- ✅ **Spec Generator**: Después de generar/aprobar spec
- ✅ **Backend Developer**: Después de completar implementación backend
- ✅ **Frontend Developer**: Después de completar implementación frontend
- ✅ **Database Agent**: Después de crear migrations
- ✅ **Test Engineers**: Después de generar suite de tests
- ✅ **QA Agent**: Después de generar estrategia QA
- ✅ **Documentation Agent**: Después de generar docs
