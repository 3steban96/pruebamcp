# HU-04: Login con OAuth (Google)

**Como** usuario registrado
**Quiero** iniciar sesión con mi cuenta de Google
**Para** evitar memorizar otra contraseña.

## Criterios de aceptación
1. Se muestra un botón "Continuar con Google" en la pantalla de login.
2. Al primer login OAuth se vincula la cuenta de Google al usuario existente
   si el email coincide; si no, se crea un usuario nuevo.
3. El flujo cumple OAuth 2.1 con PKCE.
4. La sesión resultante usa el mismo formato que el login tradicional.
